# Base64 Encoded Background Image

This file contains the base64 encoded version of the background image from the Figma design.

## Usage

The base64 encoded image can be used directly in CSS or HTML if needed:

```css
.background-image {
    background-image: url('data:image/png;base64,[BASE64_CONTENT_HERE]');
}
```

## Note

The actual base64 content is too large to display in this file. The original image file should be used instead for better performance and maintainability.
